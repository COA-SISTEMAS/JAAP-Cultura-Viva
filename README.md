# JAAP Cultura Viva

Sitio web inicial de la Junta de Artistas y Artesanos de Juticalpa (JAAP), Olancho, Honduras.

## Contenido
- Página principal adaptable a móviles y escritorio.
- Presentación institucional y disciplinas artísticas.
- Directorio inicial por categorías con búsqueda y filtros.
- Modal informativo para cada disciplina.
- Espacio de agenda cultural.
- Invitación para participar.

## Publicación con GitHub Pages
1. Abre **Settings** del repositorio.
2. Entra en **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama **main** y la carpeta **/ (root)**.
5. Guarda los cambios. GitHub mostrará la URL pública cuando termine el despliegue.

## Antes del lanzamiento público
- Sustituir `CONTACTO-JAAP@ejemplo.com` por el correo oficial.
- Confirmar la descripción institucional y los datos de contacto oficiales.
- Reemplazar imágenes ilustrativas por fotografías autorizadas.
- Incorporar perfiles reales únicamente con consentimiento de sus titulares.
- Definir quién actualizará la agenda y recibirá las solicitudes.

## Estado y límites de esta versión
Esta es una primera versión estática: no tiene todavía base de datos, inicio de sesión, panel administrativo ni almacenamiento de formularios. Los filtros y ventanas informativas funcionan en el navegador. Las fotografías actuales son ilustrativas y las tarjetas son categorías, no perfiles de personas reales.
